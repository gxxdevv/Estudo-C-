# Urna Eletrônica

Faça um programa que:

- apresente uma lista de candidatos;
- permita votar usando o número de cada candidato;
- contabilize os votos de cada candidato;
- identifique e contabilize votos nulos;
- mostre o resultado da votação;
- permita encerrar a votação;
- impeça novos votos após o encerramento.
