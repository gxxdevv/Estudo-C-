# GTX BANK — Sistema Bancário

Faça um programa que:

- permita criar contas bancárias;
- armazene nome, senha e saldo inicial de cada conta;
- permita realizar login utilizando nome e senha;
- limite a três tentativas de senha;
- permita acessar as operações após a autenticação;
- permita consultar o saldo da conta;
- permita realizar depósitos;
- impeça depósitos com valores negativos ou iguais a zero;
- permita realizar saques;
- impeça saques com valores maiores que o saldo disponível;
- atualize o saldo após depósitos e saques;
- permita encerrar a sessão e retornar ao menu principal;
- permita gerenciar várias contas utilizando "map" e "struct".
